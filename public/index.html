ภาพรวมทุกเกม

เพิ่มเกมเพื่อเริ่มติดตาม

เปรียบเทียบเกม

ดูจำนวนผู้เล่นของทุกเกมบนกราฟเดียวกัน คลิกชื่อเกมเพื่อซ่อนหรือแสดงเส้น

การแจ้งเตือน

ระบบบันทึกเมื่อจำนวนผู้เล่นข้ามเกณฑ์หรือดึงข้อมูลไม่สำเร็จ

ขอบเขตและนโยบายข้อมูล

ระบบนี้ออกแบบให้ใช้เฉพาะข้อมูลที่ Roblox เปิดเผยต่อสาธารณะ

ข้อมูลที่ใช้

จำนวนผู้เล่นออนไลน์ ยอดเข้าเล่น ความจุต่อเซิร์ฟเวอร์ ชื่อเกมและผู้สร้าง จาก Roblox Public API แบบอ่านอย่างเดียว ไม่ต้องล็อกอิน ไม่ใช้คุกกี้หรือบัญชี Roblox ของผู้ใช้

การเรียก API อย่างรับผิดชอบ

เรียกแบบรวมหลายเกมในคำขอเดียว มีแคช 20 วินาที เคารพ Retry-After เมื่อ Roblox จำกัดอัตรา และตรวจสอบอัตโนมัติสูงสุดทุก 1 นาที ระบบจะหยุดเมื่อซ่อนแท็บ

ข้อมูลผู้เล่นรายบุคคล

แดชบอร์ดนี้ไม่แสดงรายชื่อหรือรหัสผู้เล่น หากเปิดใช้สคริปต์ telemetry ในเกมของคุณเอง ข้อมูลจะถูกส่งด้วย token ลับ เก็บเฉพาะ User ID (ปิดชื่อผู้ใช้เป็นค่าเริ่มต้น) และต้องแจ้งผู้เล่นในนโยบายความเป็นส่วนตัวของเกม

การเก็บรักษา

ประวัติเก็บใน Cloudflare D1 สูงสุด 30 วันแล้วลบอัตโนมัติ รายการเกมที่ติดตามและการแจ้งเตือนเก็บในเบราว์เซอร์ของคุณเท่านั้น ขนาดเซิร์ฟเวอร์ที่แสดงเป็นค่าต่อเซิร์ฟเวอร์ ไม่ใช่จำนวนผู้เล่นทั้งเกม

ข้อมูลจาก Roblox Public API ณ เวลาที่ดึง ไม่ใช่ข้อมูลทางการของ Roblox Corporationรอการตรวจสอบครั้งแรก
